# Egern Widgets

个人 Egern 小组件 & 模块集合。

## 红宝书随机单词

考研英语红宝书随机单词小组件，每次刷新展示下一个单词及有道词典释义。

### 功能

- 📖 自动拉取 2026 考研英语红宝书词表（6700+ 词）
- 📝 有道词典标准释义，带词性标注
- 🔄 每 30 分钟自动刷新
- 🎨 适配所有小组件尺寸（含锁屏）

### 安装

在 Egern 中导入以下模块链接：

```
https://raw.githubusercontent.com/Tiomehsh/egern/main/widget/random-word.yaml
```

添加 Egern 小组件到主屏幕，选择 **红宝书随机单词**。
